# よりみち前の30分

端末内に勉強時間、提出物、テスト、教科ごとの記録を保存する、オフライン対応の小さな PWA です。外部 CDN やアクセス解析は使いません。

## ローカルで開く

`app` フォルダを、HTTP サーバーのドキュメントルートにして開きます。サービスワーカーは `file:` URL では登録できないため、`http://localhost/.../` でアクセスしてください。

例（Python がある場合）:

```text
cd app
python -m http.server 4173
```

`http://localhost:4173/` をブラウザで開き、アプリの設定や記録を試せます。データはブラウザの IndexedDB に保存されます。Node.js など別の静的 HTTP サーバーを使う場合も、`app` をドキュメントルートにしてください。

## 時間割と固定教科

「設定」→「時間割」で曜日ごとの勉強枠を設定できます。「＋ 時間枠」で同じ曜日に複数の枠を追加し、各枠の「固定する教科」から数学・英語・資格などを割り当てます。固定教科を設定した枠は「今日の予定」に教科名と「この枠で始める」ボタンが表示されます。教科を固定しない枠は、勉強開始時に教科を選べます。日付ごとの時間割変更でも同じ設定ができます。

## GitHub Pages で使う

この `app` フォルダの中身を Pages の公開対象に置きます。`manifest.webmanifest` と `sw.js` の `./` 相対パスは、ドメイン直下とプロジェクトサブパスの両方で動くようになっています。Pages 側で HTTPS を有効にしてから、公開 URL をブラウザで開いてください。

## オフラインで使う

初回はオンラインで URL を一度開き、サービスワーカーがアプリのシェルを保存するまで待ちます。その後は、同じスコープの URL を開けば通信できない状態でも画面を表示できます。勉強記録は端末内に保存されるため、ブラウザのサイトデータを削除すると失われます。

新しい版が見つかった場合は、アプリが更新を案内します。タイマーが動いていないことを確認してから更新を適用してください。更新中にブラウザやタブを閉じても、保存済みのデータはそのままです。

## データの移行

「設定」→「JSONを書き出す」で、この端末の記録を JSON ファイルに保存できます。別の端末やブラウザでは、「設定」→「JSONを読み込む」からそのファイルを選びます。読み込み前の状態は端末内のバックアップとして保持され、直近のバックアップを設定画面から戻せます。

JSON ファイルには勉強記録、教科、予定、提出物、テストなどが含まれます。大切なデータは定期的に書き出して保管してください。
